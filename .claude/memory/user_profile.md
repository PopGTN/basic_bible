# User Profile

## Working Preferences
- Prefers work to be done in a senior-developer style with strong structure and maintainability.
- Wants task/context files kept current so work can continue cleanly across machines and agents.
- Prefers personal notes/highlights to remain clearly separate from parser footnotes and cross-references.
- Wants the app to stay plain, non-social, and app-native in UI direction.
- Wants the current app to remain a basic reader first, while leaving room for a more advanced future fork or large-screen experience later.

## Collaboration Preferences
- Values direct progress over abstract planning once scope is clear.
- Wants risky or incomplete areas called out honestly.
- Prefers separate task tracking for unrelated work so agents do not mix contexts.
- Likes code and architecture decisions to preserve future extensibility without overbuilding the current phase.
